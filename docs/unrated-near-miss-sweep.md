# Unrated near-miss sweep

Branch `claude/unrated-near-miss-sweep`, branched from origin/main `2fc6ecc` (Nov 17, 2026). Pool check: Freddy confirmed the Claude Pro downgrade on Nov 17, 2026, so this ran on Sonnet 5.5.

## Why the Glory was not on the map
`prepare_data.py` matches registry rows to the flight catalog by exact normalized (brand, model) only, by design (never guess variant ratings). The PDGA registered the Royal line as "(Royal Prototype)" while every catalog lists plain names, so nothing matched and nothing queued the near-miss for a human.

## What changed
- **Batch 1 (commit 3d38d43): the Royal line.** Glory was already landed (ad30884, 7/5/0/3). Grace 11/6/-1/2, Rive 13/5/0/3.5, Trust 5/5/0/2, Faith 2/3/0/1, Hope 2/3/0/1 now rated from Latitude 64's own collection pages (checked Nov 17, 2026), equal to the catalog. Grace's page names no category; it describes a fairway/high-speed hybrid, so the catalog's "Hybrid Driver" is used.
- **Batch 2: three more MATCHes.** Discmania MD1 (Midrange Driver) 5/6/0/0, Latitude 64 Sinus (New) 2/2/0/2, Westside The Adder 13/5/0/4. Each has a manufacturer page equal to the catalog and no separately approved sibling.
- Mechanism (house precedent): a reviewed entry in `source-data/verified-model-overrides.json` per approval, as for the Glory (ad30884). `data.json` is rebuilt only through `prepare_data.py`.
- Rated count: 1183 on main -> 1188 after Batch 1 (+5) -> 1191 after Batch 2 (+3). Equal to the MATCH verdicts in this branch (8; the Glory was already in the 1183). Each batch's `data.json` diff changed only the records verdicted MATCH. `validate_data.py` passed clean after each batch.

## Verdict rules
- **MATCH:** decoration-only name difference, manufacturer's own page published numbers, no separately approved version of the same name. Added.
- **NOT A MATCH:** retool, version, variant or different mold; or a historical glossed approval whose current "(new)" version is its own record (historical approvals stay separate, per the house rule in `flightMatchNote`). Left unrated.
- **UNSURE:** evidence split, or the manufacturer number could not be verified this pass. Left unrated, for Freddy.
- Verdicts were assigned by rule, then spot-checked; the rules (not a per-row manual read) decide most NOT A MATCH rows. Treat the NOT A MATCH reasons as triage, not proof.
- Manufacturer sources: Discmania publishes numbers in product tags; Westside in the product page; Latitude 64 on its collection pages. Prodigy (H2/H3 V2), Dynamic (Supreme line, Sergeant) and Lone Star numbers could not be extracted reliably this pass. Dynamic pages did not render numbers to my fetches.

## Out of scope (noted, not chased)

## The near-miss report
```
python3 tools/near_miss_report.py          # only candidates with no verdict
python3 tools/near_miss_report.py --all    # every candidate
python3 tools/near_miss_report.py --json
```
It reads `source-data/flights.json` and `public/data.json` and writes nothing. A candidate is hidden once `source-data/near-miss-verdicts.json` has a row for its (id, catalogName). Run it after each data refresh; today it prints 0 un-verdicted candidates. Add a row (MATCH rows also need an override entry) for each new one a human reviews.
